👑 至尊版 IP 解題新手教學

步驟 1：選擇子網路遮罩 (CIDR)

看題目給你的網路區段後面是幾號（例如 /25、/26 或 /27），在第一欄下拉選單選擇對應的選項。

步驟 2：填入伺服器 IP

將題目中給的「伺服器位址」完整輸入到第二欄中（例如 218.216.101.151）。

步驟 3：輸入您的座號（崗位號碼）

輸入你抽到的考試座位號碼（例如抽到 20 號就輸入 20）。
